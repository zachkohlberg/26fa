CSC 111 Data Structures and Abstractions

A1: Monster Battle

This program simulates a series of battles between a hero and several monsters (technically the hero is also a monster, but nobody else needs to know that). It involves the following topics:

  • Writing a class to represent a simple object (Monster)
  • Writing code that instantiates and uses the public API of a class you wrote
  • Reading from a text file and handling exceptions

Submission

Submit this assignment on Canvas, attaching the following files:

  • Monster.java
  • MonsterBattle.java

Please don’t zip them or include extra files with them. I don’t need any of the text files you used during your own testing.

Code Restrictions

You must use the parts of the Java API that we covered in class for File I/O and exception handling. Do not use the java.nio package or any static variables in your program.

Tasks

1. Monster Class (5 points)

Write a Monster class (Monster.java). This class must have the variables, constructors, and methods described below. You should not have any other instance variables or static variables. You’re free to include other methods and constructors if you wish.

  • instance variables (must be private)
    • name: String
    • health: double
    • strength: double
  • constructor
    • Monster(String, double, double) initializes the name, health (second parameter), and strength (third parameter)
  • methods
    • getter methods: getName(), getHealth(), and getStrength()
    • attack(): double returns a random number from 0.0 to strength (strength multiplied by Math.random())
    • takeDamage(double): void decreases the monster’s health by the parameter, which represents how much damage the monster took
    • isAlive(): boolean returns true if the monster’s health is positive and false otherwise
    • toString(): String returns a String containing the monster’s name, health, and strength, with health and strength rounded to two decimal places

Use the following test program to verify your Monster class works:

public class MonsterTest {
    public static void main(String[] args) {
        Monster a = new Monster("Goblin", 100, 10);

        System.out.printf("%s is here to show how monsters work!\n", a.getName());
        System.out.printf("%s has the following stats:\n", a.getName());
        System.out.printf("\thealth: %.2f\n", a.getHealth());
        System.out.printf("\tstrength: %.2f\n", a.getStrength());
        System.out.println();

        System.out.println("We can also print the monster like this:");
        System.out.println(a);
        System.out.println("If that doesn't look right, then you need to fix your toString().");

        System.out.printf(
                "%s accidentally punches itself to demonstrate attacking:\n", a.getName());

        // monster a attacks something
        double damage = a.attack();

        // monster a receives the damage from an attack
        a.takeDamage(damage);

        // we report the incident
        System.out.printf("%s attacked %s for %.2f damage.\n", a.getName(), a.getName(), damage);
        System.out.println(a);

        // falling rocks are a workplace hazard
        double boulderDamage = 100;
        a.takeDamage(boulderDamage);
        System.out.printf(
                "A large boulder landed on %s, dealing %.2f damage!\n", a.getName(), boulderDamage);

        if (a.isAlive()) {
            System.out.printf("%s survived the boulder.\n", a.getName());
        } else {
            System.out.printf("%s was squashed by the boulder.\n", a.getName());
        }
    }
}

2. Load Monster Function (5 points)

In a separate MonsterBattle class (MonsterBattle.java), write a static loadMonster() method that takes a string representing a filename and returns a monster with the properties given in the file. Expect the file to contain the monster’s name, health, and strength in that order, each on a separate line. For example:

Sans
1.0
1.0

You may assume all files this method attempts to read are formatted correctly.

If any number in the file is exactly zero, then replace it with 100. If a monster has negative health when saved, then write 0 to the file instead of a negative value.

Requirements:

  • First task is complete
  • Returns a monster with the correct properties when given a valid file
  • Returns a default monster or null (your choice) if the file doesn’t exist
  • Must correctly handle a FileNotFoundException with try-catch
  • Must close the scanner when finished reading the file

3. Battle Function (5 points)

Add a static battle method to your MonsterBattle class that takes two Monster parameters and has them take turns attacking until one is dead. Print a summary of each attack: state the name of the attacker, the amount of damage, and the name of the defender.

Include a description of how badly the monster was damaged by each attack. A minor hit is 0 to 5 damage, a medium hit is 6 to 15 damage, and a serious hit is more than 15 damage.

Advice:

  • Look at the example code from the monster lab if you’re not sure how to do this

Requirements

  • First task is complete
  • Starting with the first parameter, monsters alternate between attacking each other and continue until one runs out of health
  • Uses the attack and takeDamage methods correctly to make each monster attack the other (use attack to generate the damage and pass it to takeDamage to apply the damage)
  • Feedback is printed for attacks as described above

4. Main Function (5 points)

Add a main method to your MonsterBattle class so we can run it as a program. Your program should do the following:

  • Load four monster files: Hero.txt, Minion1.txt, Minion2.txt, Boss.txt
    • You can make up whatever names and stats you want for each monster, but I will use my own when testing and will expect your code to load the names shown above (always assume filenames are case-sensitive)
  • Print all of the monsters
  • Have the hero fight the other three monsters in order until either the hero dies or all three other monsters die
  • Print a summary after the battles are over:
    • State whether the hero won or lost
    • List the names of any monsters the hero defeated
    • If the hero won, then print them so we can see their stats at the end of the journey
    • If the hero lost, then print the monster that defeated the hero
    • Include any other descriptive text or formatting you would like
